# Student Management System

A simple Student Management System developed using Python and SQLite.

## Features
- Add Student
- View Student Records
- Update Student Details
- Delete Student Records

## Technologies Used
- Python
- SQLite

## How to Run

1. Download the project
2. Open terminal
3. Run:

python main.py
